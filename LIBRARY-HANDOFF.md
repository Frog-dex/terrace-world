# Terrace World Library and Software handoff

Prepared by: Codex

## Target and ownership

The target is `https://frog-dex.github.io/terrace-world/library.html` in this repository (`Frog-dex/terrace-world`). The main menu's Learn destination opens it. The active game remains `terrace-world.html`; this work does not edit that file.

`library-catalog.json` is the integration map. It lists 16 already-public books, their authored cover files, 3 CD software cases, and world/planner links. `library.html` is a static rendered snapshot of that catalog, generated by `tools/build_library.py`; `library.js` handles section selection and reading. Re-run that generator or keep the HTML in sync when catalog entries change. The six CD images and sixteen book covers are copied from `/Users/blu/gm-site/images/covers/` into `library-assets/`.

## Book reading

Thirteen books open the published reader at `https://spiritstriker.app/flipbook.html` with a `pdf` query pointing to the published PDF on that domain. No PDFs are duplicated here. The reader is embedded inside this GitHub page and offers a full-page escape link. The two progression-locked books (Legal Corpus and Citizen Kit) send readers to the original Library so its read-to-unlock chain remains authoritative. The Cycle of the Galaxy is the first chain book and may open directly. Progress and unlock state on `spiritstriker.app` do not synchronize to this GitHub origin. Before changing this, inspect the original rule in `/Users/blu/gm-site/library-source.html` and its storage keys. Do not claim shared progress until it is implemented and tested.

## Software

Plan & Code, Krita Agent, and Card Forge each have the original DVD case and disc image, a verified public `Frog-dex` repository link, and only verified public launches. GitHub source links are not installers or release downloads. Plan & Code's web planners are public; Krita Agent is a plugin and Card Forge's local deck editor is not hosted publicly. The original 3D CD machine remains available at `https://spiritstriker.app/software.html`. The separate newer local 3D port at `/Users/blu/spirit-tools/` is not copied into this GitHub repository. If integrating it later, audit every launch URL: its local `/dock/` routes and account/OS placeholders must not become dead public controls. The original design rule from `/Users/blu/gm-site/SOFTWARE-SHELF-TEMPLATE.md` is that books are Toga's native medium; software appears as recovered, weathered CD artifacts.
